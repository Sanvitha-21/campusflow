# CampusFlow

## Project Description
CampusFlow is a smart campus task management system
designed to improve task assignment and tracking
between faculty and students.

## Features
- Faculty and Student Login
- Separate Dashboards
- Task Creation and Assignment
- Task Progress Tracking
- AI-based Task Priority Recommendations
- AI Chatbot
- Smart Team Recommendations

## Technologies Used
- HTML
- CSS
- JavaScript
- Google Gemini AI
- LocalStorage

## Societal Impact
- Fair workload distribution
- Reduced student stress
- Inclusive participation
